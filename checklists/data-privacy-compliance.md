# Data Privacy Compliance Checklist

Ensure compliance with NDPR (Nigeria Data Protection Regulation) and
GDPR (General Data Protection Regulation) before processing any
customer database for reactivation campaigns.

---

## NDPR Compliance (Nigeria)

### Lawful Basis for Processing

- [ ] Identified lawful basis for contacting dormant customers:
  - [ ] **Consent** — Customer previously opted in to marketing communications
  - [ ] **Legitimate interest** — Existing customer relationship (preferred basis)
  - [ ] **Contract** — Processing necessary for existing contract
- [ ] Documented the lawful basis in campaign records
- [ ] Legitimate interest assessment completed (if using legitimate interest)

### Data Subject Rights

- [ ] Mechanism in place for customers to:
  - [ ] Access their personal data
  - [ ] Request correction of inaccurate data
  - [ ] Request deletion of their data
  - [ ] Object to processing (opt-out)
  - [ ] Withdraw consent
- [ ] Response process documented (must respond within 30 days)
- [ ] Contact details for data requests published

### Data Protection

- [ ] Personal data stored securely (encrypted at rest)
- [ ] Access limited to authorised personnel only
- [ ] Data processing agreement (DPA) signed with client
- [ ] Data processing agreement signed with email platform provider
- [ ] No personal data shared with unauthorised third parties
- [ ] Data retention policy defined (how long data is kept)
- [ ] Data breach notification process documented

### NDPR-Specific Requirements

- [ ] Data Protection Compliance Organisation (DPCO) appointed (if applicable)
- [ ] Annual data protection audit scheduled (if processing large volumes)
- [ ] Privacy policy updated to reflect reactivation activities
- [ ] NITDA registration confirmed (if required for data controller)

## GDPR Compliance (EU/UK Customers)

*Only required if database contains EU/UK residents*

### Lawful Basis

- [ ] Lawful basis identified under GDPR Article 6:
  - [ ] **Legitimate interest** (most common for B2B reactivation)
  - [ ] **Consent** (required for B2C in most EU countries)
- [ ] Legitimate Interest Assessment (LIA) documented
- [ ] Records of processing activities maintained (Article 30)

### Consent Requirements

- [ ] Original consent was freely given, specific, informed, and unambiguous
- [ ] Consent records available (date, method, scope)
- [ ] Consent not older than reasonable period (typically 2 years)
- [ ] Easy withdrawal mechanism in place

### Data Subject Rights (GDPR)

- [ ] Right to access (respond within 30 days)
- [ ] Right to rectification
- [ ] Right to erasure ("right to be forgotten")
- [ ] Right to restrict processing
- [ ] Right to data portability
- [ ] Right to object to direct marketing
- [ ] Automated decision-making transparency

### Technical Measures

- [ ] Data encrypted in transit (TLS/SSL)
- [ ] Data encrypted at rest
- [ ] Access controls implemented (role-based)
- [ ] Audit logs maintained
- [ ] Data minimisation applied (only necessary fields processed)
- [ ] Pseudonymisation applied where possible

### Cross-Border Transfers

- [ ] Data transfer mechanisms in place if data leaves EU/UK:
  - [ ] Standard Contractual Clauses (SCCs)
  - [ ] Adequacy decision
  - [ ] Binding Corporate Rules
- [ ] Email platform's data processing location confirmed

## General Best Practices (All Markets)

### Email Compliance

- [ ] Physical mailing address included in all emails
- [ ] Clear sender identification in all emails
- [ ] Unsubscribe link in every email (one-click preferred)
- [ ] Unsubscribe requests processed within 48 hours
- [ ] Suppression list maintained and checked before every send
- [ ] No purchased or scraped email lists used
- [ ] Bounce handling configured (remove hard bounces immediately)

### WhatsApp Compliance

- [ ] Only contacting customers who previously shared their number
- [ ] WhatsApp Business terms of service followed
- [ ] Opt-out mechanism available ("Reply STOP to unsubscribe")
- [ ] Not sending more than 2 WhatsApp messages per week
- [ ] Business account verified and legitimate

### SMS Compliance

- [ ] Prior consent obtained for SMS marketing
- [ ] Opt-out mechanism included ("Reply STOP")
- [ ] Sending only during appropriate hours (8am-9pm local time)
- [ ] DND (Do Not Disturb) registry checked (Nigeria: NCC DND list)

### Record Keeping

- [ ] Campaign records maintained for minimum 3 years
- [ ] Consent records backed up securely
- [ ] Opt-out/unsubscribe records maintained permanently
- [ ] Data breach log maintained
- [ ] Compliance review scheduled quarterly
