# Client Database Audit Checklist

Use this checklist when auditing a new client's customer database for
reactivation potential. Complete all sections before presenting the
reactivation proposal.

---

## 1. Data Collection

- [ ] Requested full customer/contact list export (CSV preferred)
- [ ] Requested purchase/transaction history (last 2-3 years minimum)
- [ ] Requested email marketing platform export (Mailchimp, Brevo, etc.)
- [ ] Requested WhatsApp Business contact export
- [ ] Requested CRM access or export (read-only)
- [ ] Checked for additional data sources:
  - [ ] Point-of-sale / invoicing system
  - [ ] Accounting software (QuickBooks, Xero, etc.)
  - [ ] Instagram/Facebook DM history
  - [ ] Old spreadsheets and CSV exports
  - [ ] Business card collections
  - [ ] Event attendee lists
- [ ] Signed data processing agreement (DPA) with client
- [ ] Confirmed data privacy compliance (NDPR/GDPR)

- [ ] Total contact count recorded: ______
- [ ] De-duplicated records (by email + phone)

- [ ] Duplicate rate: ______%

  - [ ] Valid emails: ______
  - [ ] Invalid emails: ______
  - [ ] Catch-all emails: ______
  - [ ] Disposable emails: ______
- [ ] Email validity rate: ______%
- [ ] Phone number format standardised (with country codes)

## 5. Revenue Estimation

- [ ] Average order value (AOV) confirmed: ______

- [ ] Revenue projections calculated:
  - [ ] Conservative (10%): ______
  - [ ] Moderate (15%): ______

- [ ] ROI projection presented to client

## 6. Technical Readiness

- [ ] Email platform selected/confirmed (Brevo, Mailchimp, etc.)
- [ ] Email sending domain authenticated (SPF, DKIM, DMARC)
- [ ] WhatsApp Business account set up
- [ ] CRM configured for tracking
- [ ] Automation workflows mapped
- [ ] Unsubscribe mechanism in place
- [ ] Tracking pixels/UTMs configured

## 7. Compliance

- [ ] Data privacy compliance confirmed (see data-privacy-compliance checklist)
- [ ] Unsubscribe/opt-out mechanism tested
- [ ] Data retention policy documented
- [ ] Client approval obtained for reactivation campaign

## 8. Campaign Readiness

- [ ] Email templates customised for client brand
- [ ] WhatsApp templates customised
- [ ] Personalisation fields mapped and tested
- [ ] Test emails sent and reviewed
- [ ] Automation triggers configured
- [ ] Success metrics defined and tracking set up
- [ ] Campaign brief completed (see reactivation-campaign-brief.md)
- [ ] Client sign-off obtained
