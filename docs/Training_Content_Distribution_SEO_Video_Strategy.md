5. **Authority-building** — positions M4E as the Nigerian CRM training expert

**Estimated SEO impact of publishing all Tier 1 content:**
- 30+ new indexable pages
- 50+ long-tail keyword rankings
- 200+ internal links strengthening site authority
- 15+ FAQ-rich pages for featured snippets

### 3.2 How Training Content Drives AEO

AI answer engines (ChatGPT, Perplexity, Google AI Overviews) cite content that is:

1. **Authoritative** — From a recognised domain with expertise signals
2. **Structured** — Clear headings, lists, tables, definitions
3. **Question-answering** — Directly answers common questions
4. **Unique** — Contains information not found elsewhere
5. **Fresh** — Recently published or updated

Our training content scores highly on all five because:
- It is **the only** Nigerian-market-specific CRM training content online
- It uses clear headings, numbered steps, and practical examples
- Every module answers specific "how do I..." questions
- It contains unique Nigerian business examples (₦ pricing, local scenarios)
- It will be freshly published with regular updates

**AEO-specific optimisations per page:**

| Element | Implementation | AEO Benefit |
|---------|---------------|-------------|
| FAQ sections | Every page ends with 3-5 Q&As | Direct answer extraction |
| Definition blocks | Key terms defined in `<dl>` tags | Knowledge graph entries |
| Step-by-step lists | Numbered procedures | How-to citations |
| Comparison tables | Feature vs feature | Comparison queries |
| Nigerian context | ₦ amounts, local examples | Geo-specific authority |
| Schema markup | Article, HowTo, FAQPage, Course | Structured data signals |

### 4.2 Conversion Process

Each training document goes through a **four-stage conversion**:

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  STAGE 1     │    │  STAGE 2     │    │  STAGE 3     │    │  STAGE 4     │
│  Script      │───▶│  Audio       │───▶│  Visuals     │───▶│  Assembly    │
│  Adaptation  │    │  Generation  │    │  Production  │    │  & Export    │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
     │                    │                    │                    │
  OpenRouter           edge-tts            Remotion +           ffmpeg +
  Gemini 2.5         Nigerian EN          AI images           Remotion
  Flash               voices              + Pexels
```

#### Stage 1: Script Adaptation

**Tool:** OpenRouter API (Gemini 2.5 Flash)  
**Cost:** ~₦4 per script (~$0.003)

The training document is converted into a video script with:
- Scene-by-scene breakdown
- Voiceover narration text
- Visual direction per scene (what to show)
- On-screen text overlays
- Timing estimates

**Script format matches the existing video pipeline's Stage B output:**
```json
{
  "title": "What is a CRM and Why Your Business Needs One",
  "scenes": [
    {
      "scene_number": 1,
      "type": "brand_intro",
      "duration": 5,
      "narration": "Welcome to Marketing4Effect...",
      "visual_direction": "M4E branded intro animation"
    },
    {
      "scene_number": 2,
      "type": "text_overlay",
      "duration": 8,
      "narration": "Imagine you own a restaurant in Lagos...",
      "visual_direction": "Busy Nigerian restaurant scene",
      "text_overlay": "Your Customers Are Your Business"
    }
  ]
}
```

#### Stage 2: Audio Generation

**Tool:** edge-tts (Nigerian English voices)  
**Cost:** Free (₦0)

- Voice: en-NG-AbeoNeural (male) or en-NG-EzinneNeural (female)
- Phonetic corrections for Nigerian names applied
- Per-scene audio files generated
- Whisper timestamps for subtitle alignment (optional)

**Note on voice quality:** edge-tts Nigerian voices are functional but not authentic-sounding. For premium content, consider hiring a voice actor and using Chatterbox voice cloning (one-time ₦160K investment for unlimited generation). For initial launch, edge-tts is acceptable.

#### Stage 3: Visual Production

**Tool:** Existing video pipeline (Remotion + AI images + Pexels)  
**Cost:** ~₦80-120 per video (~$0.06-0.09)

The pipeline already handles:
- Brand intro/outro (Remotion BrandIntro template)
- Text overlay scenes (Remotion TextOverlay or ffmpeg)
- AI-generated images (fal.ai)
- Stock footage (Pexels API)
- Thumbnail generation

#### Stage 4: Assembly & Export

**Tool:** ffmpeg + Remotion  
**Cost:** Free (₦0)

- Scene concatenation with crossfade transitions
- Background music mixing (LUFS normalisation)
- Subtitle burning (optional)
- Multiple format export:
  - YouTube (1920×1080, 16:9)
  - Instagram/TikTok (1080×1920, 9:16)
  - Website embed (1280×720, 16:9)
  - Thumbnail (1280×720, JPEG)

### 4.3 Batch Production Script

A new script wraps the existing pipeline for batch processing:

```
Input:  /training/curriculum/level1_getting_started/module_01_*.md
                    ↓
Step 1: Generate video script (OpenRouter)
                    ↓
Step 2: Generate voiceover (edge-tts)
                    ↓
Step 3: Generate visuals (pipeline Stage D)
                    ↓
Step 4: Assemble video (pipeline Stage E+F)
                    ↓
Output: /training/videos/module_01_what_is_crm.mp4
        /training/videos/module_01_what_is_crm_vertical.mp4
        /training/videos/module_01_what_is_crm_thumb.jpg
        /training/videos/module_01_what_is_crm_meta.json
```

**Estimated batch production time for 39 priority videos:**
- Script generation: ~2 hours (automated)
- Audio generation: ~3 hours (automated)
- Visual production: ~8 hours (automated, GPU-limited)
- Assembly: ~4 hours (automated)
- **Total: ~17 hours of automated processing**
- **Human review: ~4 hours (spot-checking quality)**

### 6.3 AEO-Specific Video Optimisation

AI answer engines increasingly reference video content. To maximise citations:

1. **Transcripts on page** — AI models read text, not video. The full transcript on the page ensures the content is extractable.

2. **Structured summaries** — Each video page includes:
   - "In this video, you'll learn:" (bullet list)
   - "Key takeaways:" (numbered list)
   - "Frequently asked questions:" (Q&A format)

3. **Timestamp-linked answers** — YouTube descriptions include:
   ```
   0:00 Introduction
   0:45 What is a CRM? (Definition)
   2:15 Why Nigerian businesses need a CRM
   3:30 How M4E CRM is different
   4:45 Getting started in 5 minutes
   ```
   AI models can reference specific timestamps.

4. **Cross-linking** — Every video page links to:
   - The text version of the same content
   - Related feature pages on the website
   - The YouTube video directly
   This creates a web of authority signals.
